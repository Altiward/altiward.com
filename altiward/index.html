See who holds admin on every Mac, and for how long

Altiward checks each Mac's real admin group against recorded grants, can remove rights that outlive them, and sends the record to your SIEM. SAP Privileges handles elevation; Altiward adds oversight across the fleet.

View Altiward on GitHub Try the console locally

What Altiward adds

Check actual admin rights

The agent reads each Mac's admin group and checks it against recorded grants and your permanent-admin list. Unexpected membership becomes a finding for your team to investigate.

Choose what the agent removes

Alert when rights outlive their grant or appear without one, or configure the agent to remove them. Request an early revocation from the console; the Mac applies it when it can reach your server.

See what changed during a session

Review detected changes to local accounts, launch items, sudoers, SSH keys and remote access. Missing check-ins show where visibility has stopped.

Bring the record into your SIEM

Send session evidence, findings and console actions to Splunk, Microsoft Sentinel or syslog as OCSF events, and correlate them with the telemetry you already collect.

Try the console locallyNeeds only Docker
git clone https://github.com/Altiward/altiward
cd altiward
docker compose -f dev/compose.demo.yaml up --build

# When you're done, from the same folder:
docker compose -f dev/compose.demo.yaml down -v

  1. The first run downloads and builds the server, which can take a few minutes.

  2. When it prints Demo ready, open http://localhost:8080 and sign in with the token dev-console-token-001.

  3. It keeps running in the background until you stop it with the last command, which also deletes the demo data. Leave out -v to keep the data for next time.

What's in the demo

Six example Macs, sent through the same signed protocol a real agent uses:

  • An admin session in progress, and one past its expiry with an overdue alert
  • Admin rights nobody granted, on a Mac whose Privileges hook doesn't match the agent's
  • An account someone added to admin by hand, with the process that did it and the console revoke that removed it
  • Privileges' tamper protection switched off, and a blocked attempt to move Privileges aside
  • A Mac that hasn't checked in for four days
  • A revoke waiting for a Mac's next check-in, and a reinstalled Mac waiting for approval

The demo doesn't connect to a SIEM, and its tokens are for the demo only.

You need git and Docker with Compose v2, which Docker Desktop includes. On Windows, run the commands in WSL 2. Fixes for common errors · Run from source
