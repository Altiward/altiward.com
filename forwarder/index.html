altiward-forwarder · Open source

SAP Privileges events in your SIEM.

Forward SAP Privileges grants and revocations as OCSF events to your SIEM. Choose a relay you host or a hook on each Mac; SAP Privileges remains the elevation tool.

View forwarder on GitHub Set up the relay Set up the hook

Free and open source under Apache 2.0. No Altiward agent needed. Compare it with Privileges' own remote logging.

How it works

Two routes from Privileges to your SIEM.

Choose one for your Macs. Either way, each event is marked unverified: it's the Mac's own report.

A relay you host
A container takes SAP Privileges' webhook, stores each event on disk before it answers, and forwards it to each SIEM you set up. Macs prove who they are with a client certificate, or a secret in the URL where certificates aren't an option.
A hook on each Mac
Privileges runs a signed hook after each change, which sends the event straight to your SIEM and keeps it queued while the Mac is offline. There's no relay to host, but each Mac holds a token for your SIEM, so use one that can only send events.

What it can't tell you

The Mac's own report, forwarded.

Nothing checks the events
Every record is marked unverified. A local admin can stop SAP Privileges from reporting.
Changes made outside Privileges
They show up only as Privileges' "changed by another process" report, and only while its agent runs.
No sessions
Grants and revocations arrive as separate events, not paired into sessions.
For verified records
Run the Altiward agent: it watches the admin group itself, reports changes Privileges didn't make and can remove rights past their expiry. The relay and the agent can run on the same Macs. See how Altiward works.
How the projects fit together

Event forwarding and admin oversight.

altiward-forwarder
Event forwarding for teams that want SAP Privileges grant and revocation records in their SIEM.
Altiward oversight
The Altiward agent checks actual admin membership, adds configurable expiry enforcement and console revocation, and records session evidence. SAP Privileges grants access. See how Altiward works.
altiward-siem
Detection rules, hunting queries and saved searches for Sentinel and Splunk. Both projects send the same OCSF records, so the content marked for the forwarder works with its events too. See the detections.
