Altiward guide · SIEM evidence

Mac admin evidence in your SIEM

Send Altiward session evidence, findings and console actions to Splunk, Microsoft Sentinel or syslog. Start with the supported integrations and confirm delivery from Mac to SIEM.

Last reviewed October 2026Splunk · Microsoft Sentinel · syslogOCSF

The Altiward agent checks the Mac's admin group against recorded grants and your permanent-admin list. Your server exports the resulting events as OCSF, with CEF also available for syslog. You configure the destination; no session evidence goes to Altiward.

1. Choose your Altiward integration

The setup files live with the code on GitHub. Use the guide for your destination rather than building a separate receiver for SAP Privileges events.

Configure the server using Connect your SIEM in the install guide. Events wait in the server's Postgres outbox until the destination accepts them, so a SIEM outage delays delivery.

2. Verify a session end to end

  1. Request temporary admin through SAP Privileges on an enrolled Mac. Give a reason you can recognise.
  2. Find the session in the Altiward console. Check the user, Mac, recorded reason, grant time and expiry.
  3. Revoke the session while the Mac can reach the server, then confirm that its admin rights have ended.
  4. Find the corresponding events in your SIEM and compare them with the console record.

The console and SIEM walkthrough shows example records. Use your deployment's event fields and timestamps when adapting searches.

3. Decide which findings need a response

  • Admin rights without a recorded grant: check the account's purpose and your permanent-admin list.
  • Detected changes during a session: correlate new local accounts or other persistence changes with your security telemetry.
  • Rights past expiry: check your configured expiry policy and the recorded outcome. Alerting is the default; removing rights requires enforcement to be enabled.
  • Missing check-ins: investigate a loss of visibility. The finding does not establish why the Mac stopped reporting.

Altiward records admin rights and detected changes. Use your EDR and other logs to investigate commands and process activity. See the event schema for the contract and example fixtures.

Start with the Sentinel analytics rules and Splunk saved searches in altiward-siem. Adapt them to your environment and response process.
